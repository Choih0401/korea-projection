# 내 차 제보 가이드

Korea Projection은 **한국 차라면 일단 켜 봅니다**(1.5.2부터). 설치하면 HMG-API가 내 차에서 지도를 만들어 맞는지 확인하고, 맞으면 무선 카플레이를 켭니다.

그래서 이 글은 이럴 때 씁니다.

- **되면:** "됐다"고 알려 주세요. 지원 목록에 **✅ 됨**으로 올립니다.
- **안 되면:** 아래 파일 3개를 보내 주세요. 그 안의 기록으로 원인을 찾습니다.

저희는 여러분의 차를 직접 만져 볼 수 없습니다. **보내 주시는 파일 3개가 전부입니다.** 천천히 따라 해 주세요.

> 걸리는 시간: 차에서 5분, 컴퓨터에서 5분
> 필요한 것: USB 메모리 1개, 컴퓨터 1대, GitHub 계정(무료)

---

## 준비물 확인

아래 네 가지가 모두 "예"이면 시작하세요.

| 확인할 것 | 어떻게 확인하나요? |
|---|---|
| 내비에 **NEMESIS**가 있나요? | 내비 화면에 **NEMESIS Manager**가 보이면 됩니다. |
| **HMG-API**가 설치되어 있나요? | NEMESIS Manager → **My Packages** 목록에 **HMG-API**가 보이면 됩니다. |
| **Korea Projection 1.5.2 이상**이 설치되어 있나요? | 같은 목록에 **Korea Projection**이 있으면 됩니다. 설치는 [설치 가이드](install-guide.md)를 보세요. |
| USB 메모리가 **FAT32**인가요? | 설치할 때 쓴 USB를 그대로 쓰면 됩니다. |

---

## 1단계: 차에서 파일 만들기 (5분)

1. **차를 세우고** 시동을 켭니다.
2. 내비 화면이 다 뜰 때까지 **1~2분 기다립니다.**
3. USB를 꽂습니다.
   - "Korea Projection을 설치할까요?" 같은 창이 뜨면 **아니요**를 누릅니다.
4. 내비에서 **NEMESIS Manager**를 엽니다.
5. **My Packages** → **Korea Projection** → **Launch**를 누릅니다.
6. 화면 아래에 이 글자가 뜹니다.
   > 제보 자료를 USB의 KoreaProjection-report 폴더에 저장하는 중입니다(약 1분).
7. **그대로 1~2분 기다립니다.** USB를 빼지 마세요. 시동도 끄지 마세요.
8. 이 글자가 뜨면 끝입니다. 이제 USB를 빼세요.
   > 제보 자료를 모두 저장했습니다(USB의 KoreaProjection-report 폴더, 파일 3개). 이제 USB를 빼셔도 됩니다.

**"저장하지 못했습니다"가 뜨면:** USB를 뺐다가 다시 꽂고, 4번부터 다시 하세요.

---

## 2단계: 파일 3개 확인하기 (컴퓨터)

USB를 컴퓨터에 꽂고 엽니다. **`KoreaProjection-report`라는 폴더**가 있습니다. 그 폴더를 엽니다.

```
USB
└─ KoreaProjection-report        ← 이 폴더를 엽니다
   ├─ 1-report.md                ← 차 정보
   ├─ 2-car-report.json          ← 차 안 프로그램 위치 정보
   └─ 3-log.txt                  ← 무슨 일이 있었는지 적힌 기록
```

**파일 3개가 모두 있으면 됩니다.** 다른 파일이나 폴더(예: `HMG-API reports`)는 신경 쓰지 않아도 됩니다.

- 파일이 2개뿐이고 `2-car-report.json`이 없으면, 1단계를 한 번 더 해 주세요. 그래도 없으면 있는 파일만 보내 주세요.

### 개인정보가 걱정되면

`1-report.md`와 `3-log.txt`는 메모장(Mac은 텍스트 편집기)으로 열어 읽어 볼 수 있습니다.

- **들어 있지 않은 것:** Wi-Fi 이름, Wi-Fi 비밀번호, 휴대폰 이름, 차대번호(VIN), 전화번호
- 휴대폰 블루투스 주소와 IP 주소는 `xx:xx:xx:xx:xx:xx`, `x.x.x.x`처럼 **이미 지워져** 있습니다.
- 그래도 내 정보가 보이면 그 줄을 지우고 저장한 뒤 보내 주세요. 그리고 저희에게도 알려 주세요.

---

## 3단계: 보내기 (컴퓨터, 5분)

1. 이 링크를 엽니다: **[차량 제보 양식](https://github.com/StopDragon/korea-projection/issues/new?template=car-report.yml)**
   - GitHub에 로그인하라고 나오면 로그인합니다. 계정이 없으면 무료로 만들 수 있습니다.
2. 칸을 채웁니다.

| 칸 | 이렇게 쓰세요 |
|---|---|
| 차종과 연식 | 예: `2021 현대 쏘나타 DN8 하이브리드` |
| 내비 소프트웨어 버전 | `1-report.md`를 열어 **"펌웨어"** 줄을 그대로 복사합니다. 예: `DN822HEV.KOR.0000.V039.001.260902` |
| 결과 | 새 차 제보면 **기타**, 시험 중인 차면 **실제 결과**를 고릅니다 |
| 제보 파일 3개 | 아래 3번처럼 **파일 3개를 한꺼번에** 끌어다 놓습니다 |

3. **파일 3개를 한꺼번에 넣는 방법**
   - `KoreaProjection-report` 폴더를 엽니다.
   - 키보드로 **모두 선택**합니다. Windows는 `Ctrl` + `A`, Mac은 `⌘` + `A`
   - 선택한 파일 3개를 마우스로 끌어서 **"제보 파일 3개" 칸에 놓습니다.**
   - 칸에 파일 이름 3개가 나타나면 성공입니다. 올라가는 데 몇 초 걸립니다.
4. 맨 아래 **Submit new issue**(제출)를 누릅니다. 끝입니다! 🎉

**적지 마세요:** 비밀번호, 차대번호(VIN), 전화번호, 휴대폰 이름

## 그다음에는

### 처음 설치했을 때 (목록에 없는 차)

1. [설치 가이드](install-guide.md)대로 설치합니다.
2. 설치하고 **3~5분** 기다립니다. 내 차에서 지도를 만드는 데 시간이 조금 더 걸립니다.
3. 이 글자가 뜨면 준비된 것입니다.
   > 무선 카플레이 설정을 마쳤습니다(시험 중인 차). 내비를 재부팅해 주세요(RESET 버튼 또는 NEMESIS 재부팅). 되는지 제보해 주시고, 유선 카플레이까지 안 되면 Korea Projection을 삭제하세요.
   - "지도를 만들지 못했습니다"나 "지도 확인에 실패했습니다"가 뜨면, 이 차에서는 아직 켤 수 없다는 뜻입니다. 아무것도 바뀌지 않았습니다. 이 가이드대로 파일 3개를 보내 주세요.
4. **내비를 재부팅합니다.** 시동만 끄면 내비가 꺼지지 않을 수 있습니다. 내비 본체의 **RESET 버튼**(작은 구멍)을 클립으로 누르거나, **NEMESIS Manager**에서 **재부팅**을 누르세요. ([자세히](install-guide.md#내비-재부팅하는-법))
5. 아이폰에서 **설정 → 일반 → CarPlay**로 연결해 봅니다.
6. **결과를 알려 주세요.** 이 가이드를 처음부터 따라 하고, 결과 칸에 실제 결과를 고르면 됩니다.

### 되면

지원 목록을 **"✅ 됨"**으로 바꿉니다. 다른 차주분들도 바로 쓸 수 있게 됩니다. 감사합니다!

### 안 되면

보내 주신 `3-log.txt`를 보고 원인을 찾습니다. 한두 번 더 부탁드릴 수 있습니다.

- 언제든 원래대로 돌릴 수 있습니다. NEMESIS Manager에서 Korea Projection을 **삭제(Uninstall)**하면 됩니다. 저희가 설치했던 무선 모드도 함께 지웁니다.
- **유선 카플레이(USB 케이블)는 언제나 그대로 쓸 수 있습니다.**

## 자주 묻는 것

| 질문 | 답 |
|---|---|
| 왜 차마다 이 파일이 필요한가요? | 무선 카플레이는 내비 안의 순정 프로그램에 끼어들어 켭니다. 끼어들 위치가 차종·소프트웨어 버전마다 다를 수 있어서, 그 차에서 직접 찾은 위치가 필요합니다. |
| 같은 차종인데 연식이 달라요 | 내비 소프트웨어 버전이 다르면 따로 필요합니다. `1-report.md`의 "펌웨어" 줄을 비교해 보세요. 같으면 이미 지원될 수 있습니다. |
| 목록에 없는 차종인데 켜도 괜찮나요? | 켜기 전에 HMG-API가 내 차에서 지도를 만들어 **맞는지 먼저 확인**합니다. 맞지 않으면 켜지 않습니다. 켠 뒤에 문제가 있으면 Korea Projection을 삭제하면 원래대로 돌아갑니다. |
| 내비를 업데이트했더니 안 돼요 | 소프트웨어 버전이 바뀌면 다시 제보가 필요할 수 있습니다. 이 가이드대로 다시 보내 주세요. |
| 차에 위험하지 않나요? | 해외 차와 Wi-Fi 부품이 없는 차에서는 아무것도 바꾸지 않습니다. 바꾼 것은 HMG-API가 원본을 백업해 두었다가 삭제할 때 그대로 되돌립니다. 제보 파일은 읽기만 해서 만듭니다. |
| HMG-API 공식판에는 언제 들어가나요? | HMG-API에도 영어로 제안합니다. 반영되면 공식 모드로 옮깁니다. 그 전까지는 Korea Projection에 든 "한국 차 빌드"를 씁니다. |
