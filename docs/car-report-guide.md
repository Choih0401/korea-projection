# 내 차 제보 가이드 (지원 목록에 없는 한국 차)

내 차가 아직 지원 목록에 없을 때, 무선 카플레이가 되도록 **차 정보를 보내 주시는 방법**입니다.
보내 주신 정보로 그 차의 설정을 만들어 다음 버전에 넣습니다. 새 버전을 설치하면 자동으로 설정됩니다.

> 걸리는 시간: 차에서 약 5분, 컴퓨터에서 약 5분
> 필요한 것: USB 메모리(FAT32), 컴퓨터, GitHub 계정(무료)

---

## 한눈에 보기

1. Korea Projection을 설치합니다. 지원 목록에 없는 차에서는 **아무것도 바꾸지 않고 대기만** 합니다.
2. USB를 꽂은 채 **Korea Projection → Launch**를 누르고, **"이제 USB를 빼셔도 됩니다"**가 뜰 때까지 기다립니다.
3. 컴퓨터에서 [제보 양식](https://github.com/StopDragon/korea-projection/issues/new?template=car-report.yml)을 열고, USB에 생긴 **파일 두 개**를 첨부해 제출합니다.
4. 저희가 새 버전을 내면 업데이트하고, 결과를 알려 주세요.

---

## 시작하기 전에

| 확인 | 설명 |
|---|---|
| 내비 소프트웨어가 최신인가요? | HMG-API는 차마다 **최신 내비 소프트웨어만** 지원합니다. 업데이트할 수 있으면 먼저 하세요. |
| NEMESIS, HMG-API가 설치되어 있나요? | 내비의 NEMESIS Manager → My Packages에 **HMG-API**가 보여야 합니다. |
| Korea Projection 1.5.1 이상인가요? | 제보 자료를 자동으로 만들어 주는 버전입니다. 설치는 [설치 가이드](install-guide.md)를 따르세요. |
| USB 메모리 | 설치에 쓴 USB를 그대로 써도 됩니다. **FAT32**여야 합니다. |

---

## 1단계: 차에서 제보 자료 만들기

1. 차를 세우고 시동(또는 전원)을 켭니다. **내비 화면이 다 뜰 때까지** 1~2분 기다립니다.
2. USB를 꽂습니다.
   - Korea Projection을 설치하겠냐고 물으면, 이미 설치한 경우 **아니요**를 누르세요.
3. 내비에서 **NEMESIS Manager → My Packages → Korea Projection → Launch**를 누릅니다.
4. 10초쯤 뒤 상태 화면이 뜨고, 아래 안내가 나옵니다.
   > Korea Projection: 제보 자료를 USB에 저장하는 중입니다(약 1분). '이제 USB를 빼셔도 됩니다'가 뜰 때까지 꽂아 두세요.
5. **1~2분 기다립니다.** USB를 빼지 마세요. 시동도 끄지 마세요.
6. 아래 안내가 뜨면 끝입니다. USB를 빼세요.
   > Korea Projection: 제보 자료를 모두 저장했습니다. 이제 USB를 빼셔도 됩니다.

### 이런 안내가 뜨면

| 안내 | 할 일 |
|---|---|
| "제보 자료(Car Report)를 저장하지 못했습니다…" | USB를 뺐다 다시 꽂고 Launch를 다시 누르세요. 두 번째도 안 되면, 그대로 3단계로 가서 저장된 파일만 첨부해 주세요. |
| "제보 자료를 USB에 저장하는 중…"이 안 뜨고 "핫스팟 켜짐…"만 뜸 | 이미 지원되는 차이고 준비도 끝난 상태입니다. 제보가 필요 없습니다. 무선 카플레이를 연결해 보세요. |
| 아무 안내도 안 뜸 | USB가 FAT32인지, 끝까지 꽂혀 있는지 확인하고 다시 해 보세요. |

### 상태 화면에서 볼 것 (참고)

| 화면 | 뜻 |
|---|---|
| 노랑 "확인되지 않은 차입니다…" | 정상입니다. 지원 목록에 없어 대기 중입니다. |
| "HMG-API" 칸에 "지원 안 함, 1.0.2 이상 필요" | HMG-API를 먼저 업데이트하세요. |
| "Wi-Fi 장치: 아니요" | 이 차에는 Wi-Fi 부품이 없어 무선 카플레이가 불가능합니다. 그래도 제보해 주시면 기록해 둡니다. |

---

## 2단계: USB의 파일 확인하기 (컴퓨터)

USB를 컴퓨터에 꽂으면 아래 파일이 있습니다.

```
USB
├─ korea-projection-report.md        ← Korea Projection 리포트
└─ HMG-API reports
    ├─ (날짜·차종)….json              ← HMG-API Car Report (이것을 첨부)
    └─ (날짜·차종)….md                (읽기용, 첨부 안 해도 됨)
```

`korea-projection-report.md`는 메모장(Mac: 텍스트 편집기)으로 **열어서 읽어 보세요.**
- Wi-Fi 이름과 비밀번호는 **값 없이 길이만** 들어 있습니다.
- "순정 파일 체크섬"은 같은 차종·버전이면 누구나 같은 값입니다. 개인정보가 아닙니다.
- 개인적인 내용이 보이면 지우고 첨부하시고, 저희에게 알려 주세요.

> Car Report(HMG-API가 만듦)에 들어가는 것: 내비 기종·지역·소프트웨어 버전, 순정 프로그램 안 위치 이름(코드 아님), 설치된 모드, HMG-API 오류, 내비 네트워크 설정.
> 들어가지 않는 것: 차대번호(VIN), 전화번호, 계정. 휴대폰과 모뎀 주소는 지워서 넣습니다.

---

## 3단계: 제보하기 (컴퓨터)

1. [차량 제보 양식](https://github.com/StopDragon/korea-projection/issues/new?template=car-report.yml)을 엽니다. GitHub 로그인이 필요합니다.
   - 차의 상태 화면 오른쪽 **QR**을 폰으로 찍어도 같은 양식이 열립니다. 다만 파일 첨부는 컴퓨터가 편합니다.
2. 아래처럼 채웁니다.

| 항목 | 적을 것 |
|---|---|
| 차종과 연식 | 예: `2021 현대 쏘나타 DN8 하이브리드` |
| 내비 소프트웨어 버전 | 리포트의 "펌웨어" 줄을 그대로 복사 |
| 결과 | **기타**를 고르고, 맨 아래 메모에 "새 차 추가 요청"이라고 적기 |
| Korea Projection 리포트 | `korea-projection-report.md` 파일을 **끌어다 놓기** |
| HMG-API Car Report | `HMG-API reports` 폴더의 **`.json` 파일**을 끌어다 놓기 |
| 그 밖에 | 아이폰 기종, 순정 상태에서 무선 카플레이가 됐는지(대부분 안 됨) |

3. **Submit new issue**(제출)를 누르면 끝입니다.

**적지 마세요:** 비밀번호, 차대번호(VIN), 전화번호, 휴대폰 이름.

---

## 4단계: 새 버전이 나오면

1. 저희가 그 차의 설정(지도, 체크섬, 핫스팟 형식)을 만들어 Korea Projection 새 버전에 넣습니다.
   - 진행 상황은 제보한 이슈에 댓글로 알려 드립니다. 확인을 위해 한두 번 더 부탁드릴 수 있습니다.
2. [설치 가이드](install-guide.md)의 업데이트 방법대로 새 버전을 설치합니다.
3. 설치하고 **2~3분** 기다리면 아래 안내가 뜹니다. 그동안 Korea Projection이 HMG-API 무선 모드와 그 차의 지도를 자동으로 넣고 확인합니다.
   > Korea Projection: 무선 카플레이 설정을 마쳤습니다. 차를 껐다 켜 주세요(문 열고 닫기).
4. 시동을 끄고 → **문을 열었다 닫고** → 다시 켭니다.
5. 아이폰에서 **설정 → 일반 → CarPlay**로 연결해 봅니다.
6. **결과를 이슈에 댓글로** 알려 주세요.
   - 연결됨 / 안 됨
   - 음악, 길안내(카카오맵, T맵, 애플 지도), 계기판 회전 안내, 전화
   - 결과가 확인되어야 그 차를 **지원 목록에 올립니다.**

### 잘 안 되면
- **1~3단계를 다시 해서** 새 파일 두 개를 이슈에 댓글로 첨부해 주세요.
- 언제든 원래대로 돌릴 수 있습니다. NEMESIS Manager에서 Korea Projection을 **삭제(Uninstall)**하면 됩니다.
  - 저희가 설치했던 무선 모드도 함께 지웁니다.
- 유선 카플레이는 어떤 경우에도 그대로 쓸 수 있습니다.

---

## 자주 묻는 것

| 질문 | 답 |
|---|---|
| 왜 차마다 정보가 필요한가요? | 무선 카플레이는 HMG-API가 순정 내비 프로그램 안에 끼어들어 켭니다. 끼어들 위치가 차종·지역·소프트웨어 버전마다 달라서, 그 차에서 직접 찾은 위치(Car Report)가 필요합니다. |
| 제보하면 바로 되나요? | 아니요. 그 차용 설정을 만들어 새 버전을 내야 합니다. 보통 며칠 걸립니다. |
| 같은 차종인데 연식이 다르면요? | 내비 소프트웨어 버전이 다르면 따로 필요합니다. 리포트의 "펌웨어" 줄을 비교해 보세요. |
| 내비를 업데이트했더니 안 돼요 | 소프트웨어 버전이 바뀌면 설정을 다시 만들어야 할 수 있습니다. 같은 방법으로 다시 제보해 주세요. |
| 차에 위험하지 않나요? | 지원 목록에 없는 차에서는 아무것도 바꾸지 않습니다. 제보 자료는 읽기만 해서 만듭니다. |
| HMG-API 공식판에는 언제 들어가나요? | 저희가 HMG-API에도 영어로 제안합니다. 반영되면 공식 모드로 옮기고, 그 전까지는 Korea Projection에 든 "한국 차 빌드" 모드를 씁니다. |
