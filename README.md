# Korea Projection

한국 현대·기아 내비(Gen5W 헤드유닛)에서 **무선 카플레이**를 쓸 수 있게 해 주는 NEMESIS 패키지입니다.

한국 내수 펌웨어에서는 HMG-API 무선 모드가 Wi-Fi 핫스팟을 요청해도 순정 핫스팟이 켜지지 않습니다. 이 패키지가 부팅할 때 순정 `hostapd`(핫스팟)와 `dnsmasq`(IP 나눠 주기)를 직접 켜서 아이폰이 무선으로 붙을 수 있게 합니다.

1.5부터는 확인된 차(와 1.5.2부터 시험 지원 차·자동 시험 차)에서 **HMG-API 무선 모드와 그 차의 지도도 자동으로 설치**합니다. HMG-API 앱에서 따로 설정하지 않아도 됩니다.

> ⚠️ 차량 소프트웨어를 바꾸는 일입니다. 모든 책임은 차 주인에게 있습니다. 운행 중에는 조작하지 마세요.

3. 스팅어: 첫 리포트(1.4.1)에서 Wi-Fi 장치가 보이지 않았습니다. Wi-Fi 부품이 없는 차라면 무선 카플레이를 켤 수 없습니다(확인 안 함).

**모든 차 공통**
- **1.5.6부터 무선 카플레이 핫스팟이 5GHz(149번)입니다.** 업데이트 뒤 아이폰이 자동으로 붙지 않으면, 아이폰 **설정 → Wi-Fi**에서 차의 카플레이 네트워크 옆 ⓘ를 누르고 **"이 네트워크 지우기"**를 누른 뒤 내비를 재부팅하세요. 설정 → 일반 → CarPlay의 차 등록은 지우지 마세요. 5GHz는 니로 하이브리드와 K7 프리미어([#29](../../issues/29))에서 확인했습니다. 5GHz가 안 되는 차는 [1.5.5](../../releases/tag/v1.5.5)를 다시 설치하고 제보해 주세요.
- **무선 안드로이드 오토는 아직 어느 차에서도 연결을 확인하지 못했습니다.** 여러 차에서 "폰은 보이지만 연결이 안 된다"는 제보가 있어 원인을 조사하고 있습니다.
- 계기판 회전 안내는 직진·유턴 위주로 나오고, 좌·우회전이나 경로를 바꾼 뒤의 안내는 늦거나 나오지 않을 수 있습니다(HMG-API 무선 모드의 동작).
- Wi-Fi를 한 번도 켜지 않은 차는 처음 설치할 때 Wi-Fi를 한 번 켭니다(카플레이·블루투스가 잠시 끊길 수 있음).
- 설치 뒤 약 5분 동안 재부팅하지 마세요.
- Wi-Fi 부품이 없는 차는 켜지지 않습니다.

## 필요한 것

1. **NEMESIS** 1.16 이상
2. **HMG-API** 1.0.2 이상
3. **Korea Projection** (이 패키지)

나머지는 Korea Projection이 확인된 차에서 자동으로 갖춥니다(1.5 이상).
- **HMG-API 무선 모드**(Wireless CarPlay + Android Auto): 없으면 설치합니다. 차주가 일부러 지우거나 꺼 둔 것은 다시 설치하지 않습니다.
- **그 차의 HMG-API 지도:** 없으면 넣고, 차에 맞는지 확인합니다.
- 설치 뒤 2~3분이면 "무선 카플레이 설정을 마쳤습니다. 내비를 재부팅해 주세요"가 뜹니다. [재부팅하는 법](docs/install-guide.md#내비-재부팅하는-법)
- 넣는 무선 모드는 HMG-API 공식 모드에 한국 차를 더한 **"한국 차 빌드"**입니다. HMG-API 공식판에 한국 차 지원이 아직 없기 때문입니다([VysseCodes/HMG-API#22](https://github.com/VysseCodes/HMG-API/pull/22)). 공식판이 지원하면 공식 모드로 옮깁니다.
- Korea Projection을 삭제하면, 함께 설치했던 무선 모드도 지웁니다.

`wireless.projection` 패키지는 **필요 없습니다.**
- **니로 하이브리드가 아닌 차는 먼저 삭제해 주세요.** 두 패키지가 같은 파일을 바꾸지 않도록, wireless.projection이 설치되어 있으면 Korea Projection은 무선 설정을 하지 않고 삭제 안내만 띄웁니다(1.5.3부터).
- 니로 하이브리드는 그대로 두어도 됩니다.
- 지우면 무선 기능 파일이 함께 지워집니다. Korea Projection 1.2부터는 부팅할 때 이 파일을 자동으로 복구하고, 복구한 뒤 내비를 재부팅하라는 안내를 띄웁니다.

## 설치

처음이시면 **[설치 가이드](docs/install-guide.md)**를 따라 하세요. 포맷부터 아이폰 연결, 잘 안 될 때까지 한 단계씩 적었습니다.

1. USB를 **FAT32**로 포맷합니다(32GB 이하 USB 권장).
2. [릴리스](../../releases/latest)에서 **`korea-projection-버전-usb.zip`**을 받습니다. `NEMESIS.data`는 안에 들어 있으니 만들지 않아도 됩니다.
3. 압축을 풀고, 풀린 폴더 **안에 있는 것**을 USB **맨 위**에 복사합니다.
   ```
   USB
   ├─ NEMESIS.data
   ├─ README.txt
   └─ packages
       └─ korea.projection.zip   ← 이 파일은 압축을 풀지 마세요
   ```
4. 내비 화면이 다 뜬 뒤 USB를 꽂고, 설치할지 물으면 **예**를 누릅니다.
5. USB를 빼고 **3~5분 기다립니다.** 이 동안 재부팅하지 마세요. 1.5.5부터는 NEMESIS Manager에서 Korea Projection의 **Launch**를 누르면 설치 진행 막대가 보입니다(뜰 때까지 5~10초). "무선 카플레이 설정을 마쳤습니다" 안내가 뜨면 **내비를 재부팅합니다**(RESET 버튼 또는 NEMESIS Manager의 재부팅, [자세히](docs/install-guide.md#내비-재부팅하는-법)). 시동만 끄면 내비가 꺼지지 않을 수 있습니다. 아이폰에서 무선 카플레이를 연결합니다.

NEMESIS Manager의 Package Store에도 등록되어 있지만, 지금 스토어에는 **1.4.1**이 올라가 있습니다(새 버전 심사 중). 1.4.1은 니로 하이브리드에서만 동작하므로, 다른 차는 위 방법대로 릴리스의 USB 묶음으로 설치하세요.

## 상태 확인과 제보

NEMESIS Manager → My Packages → Korea Projection → **Launch**를 누르세요.

- 내비 화면에 **상태 화면**이 뜹니다.
  - 맨 위에 한 줄 판정이 색으로 나옵니다(초록: 준비됨/연결됨, 노랑: 확인 필요, 빨강: 문제).
  - 왼쪽에는 무선 기능, 핫스팟, DHCP, 카플레이 연결 수 같은 상태표가 나옵니다.
- 오른쪽 **QR을 폰 카메라로 찍으면** 내용이 채워진 [차량 제보](../../issues/new?template=car-report.yml) 양식이 열립니다. 차종과 결과만 고르고 제출하면 됩니다.
- QR과 리포트에는 비밀번호, SSID, 휴대폰 이름, MAC, IP가 들어가지 않습니다. 길이와 예/아니요만 적습니다.
- USB가 꽂혀 있으면 제보 자료를 USB의 **`KoreaProjection-report`** 폴더에 저장합니다: `1-report.md`(차 정보), `3-log.txt`(기록, 휴대폰 블루투스 주소·IP는 지움).
- 지원 목록에 없는 차, 시험 중인 차, 준비가 덜 된 차라면 `2-car-report.json`(HMG-API Car Report)도 **자동으로** 같은 폴더에 저장합니다(약 1분, "이제 USB를 빼셔도 됩니다"가 뜰 때까지 꽂아 두세요). 폴더 안 파일 3개를 [내 차 제보 가이드](docs/car-report-guide.md)대로 첨부해 주세요.

## 알아 두실 점

- 핫스팟이 켜져 있는 동안에는 **내비가 휴대폰 핫스팟(일반 Wi-Fi)에 붙을 수 없습니다.** 한 Wi-Fi 칩이 핫스팟 역할을 하기 때문입니다.
- 1.5.5부터는 내비의 일반 Wi-Fi 접속 기능을 잠급니다. Wi-Fi 설정 파일(`/data/misc/wifi/wpa_supplicant.conf`)의 소유자를 root로 바꿉니다. 그러지 않으면 내비의 Wi-Fi 서비스가 30초마다 Wi-Fi를 다시 시작해 핫스팟이 끊겼습니다(그랜저·K5·K7·쏘렌토·니로 PHEV 제보, 순정으로 되돌린 니로에서 재현). 한국 내수 펌웨어에는 일반 Wi-Fi 메뉴가 없어 보통은 영향이 없습니다. 삭제하면 원래대로 되돌립니다.
- 1.5.6부터 우리 핫스팟은 5GHz 149번, 40MHz(순정 핫스팟 기본값과 같은 설정)로 켭니다. 1.5.5까지는 2.4GHz 6번이었습니다. 2.4GHz로 자동으로 되돌아가지는 않습니다.
- 계기판 길안내(회전 안내)는 **휴대폰 앱이 회전 정보를 보낼 때만** 나옵니다.
  - 카카오맵: 동작 확인. 다만 회전 정보가 오지 않은 날이 한 번 있어 확인 중입니다.
  - T맵: 앱의 전체 → 연구소 → "카플레이 HUD 연동"을 켜야 합니다.
- 차 설정에서 ADB TCP가 켜져 있으면 HMG-API가 경고를 띄웁니다. 이 패키지는 `192.168.43.x` 대역을 써서 영향이 없었습니다.

## 삭제

NEMESIS Manager → My Packages → Korea Projection → **Uninstall**을 누르면 다음과 같이 정리됩니다.
- 이 패키지가 켠 핫스팟과 DHCP를 멈춥니다.
- 설정 파일, 작업 폴더, 백업을 지웁니다.
- 설치 전에 Wi-Fi가 꺼져 있던 차는 다시 끕니다.
- 잠갔던 Wi-Fi 설정 파일의 소유자·권한과 함께 치운 파일을 원래대로 되돌립니다(1.5.5).
- 삭제가 끝나면 **내비를 재부팅해 주세요**([재부팅하는 법](docs/install-guide.md#내비-재부팅하는-법)). 일반 Wi-Fi가 원래대로 돌아옵니다.

HMG-API의 무선 기능 파일은 HMG-API 것이므로 지우지 않습니다.

삭제할 때 Wi-Fi를 껐다 켜지 않는 이유가 있습니다. 니로에서 확인해 보니 Wi-Fi를 껐다 켜면 Wi-Fi·블루투스 모듈이 다시 시작되고, 블루투스 카플레이가 재부팅 전까지 되지 않았습니다(1.2까지의 동작).
