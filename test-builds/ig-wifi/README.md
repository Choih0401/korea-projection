# 그랜저 IG Wi-Fi 복구 시험판 1.7.2.2

- [전체 USB 설치 파일](korea-projection-1.7.2.2-usb.zip)
- [원래 1.7.2 전체 USB: 원복용](korea-projection-1.7.2-original-usb.zip)
- [설치·중단·진단 안내](../../docs/ig-wifi-recovery.md)
- [SHA-256](SHA256SUMS)

전체 ZIP을 풀어 USB 루트에 복사하고 NEMESIS에서 설치합니다. `packages/korea.projection.zip`은 풀지 않습니다. 기존 정식 1.7.2에서 업데이트할 때 HMG-API 무선 모드를 따로 설치할 필요가 없습니다.

공개 제보의 IGPEHEV/IGPE21 `.260902` 펌웨어에만 제한 복구가 실행됩니다. 정상 Wi-Fi는 건드리지 않습니다. 차량 실기 검증 전이며, 하드웨어·드라이버 결함을 모두 해결하는 버전은 아닙니다. K3 TBT 시험판 변경은 포함하지 않습니다.
